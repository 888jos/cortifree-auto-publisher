# Pinterest reference intake

This folder contains a first-pass visual-reference intake for CortiFree.

- `FACE_REF_*`: references with a visible person/face; use only to guide pose, framing, lighting, and action before ModelArk face replacement.
- `FACELESS_REF_*`: environment, outfit, and composition references without a usable face.
- `manifest.json`: source pin, downloaded image URL, SHA-256, and visual review decision.

Important: Pinterest image URLs are not proof of publication rights. Every item is marked `visual_reference_only`; a `candidate` means it passed an initial visual check, not that it is cleared for publication. Before any asset is used in a live post, resolve the original source and reuse license, or recreate the scene with licensed stock / ModelArk.

The intake was checked for exact duplicate files by SHA-256; no exact duplicate occurred inside this batch.
